# CodeGrapher

We build code intelligence and development tools. [DataTug](https://datatug.app)
is our flagship product; CodeGrapher helps us inspect its code structure during
development. Read [how we build DataTug with our tools](https://datatug.app/en/under-the-hood/tools-we-built/).

Explore [CodeGrapher](https://codegrapher.dev), a code graph for searching
symbols, callers, callees, and impact across a repository.
